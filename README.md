# Ivan Ezekiel — Full-Stack Developer Portfolio

An interactive, neo-brutalist bento portfolio built with **React**, **Vite**, and **Vanilla CSS**. Features live scrollspies, direction-aware floating capsule navbar, pixel-reveal page transitions, real-time timezone tracking, dynamic theme engine, tactile mechanical key sound effects, and project showcase mockups.

---

## ⚡ Tech Stack

- **Core**: React 19, React Router v7, Vite
- **Styling**: Vanilla CSS (Tailored HSL Design Tokens, Glassmorphism, CSS Grid, Flexbox)
- **Audio Synthesis**: Web Audio API (Synthesized tactile mechanical switch sounds)
- **Deployment**: Vercel

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/IvanEzkl/Ivan---Portfolio.git
cd Ivan---Portfolio
```

### 2. Install dependencies & run development server
```bash
npm install
npm run dev
```

### 3. Build for production
```bash
npm run build
```

---

## 🌐 Live Deployment on Vercel

This repository is pre-configured with `vercel.json` for zero-config deployment and SPA route rewrites:
- **Build Command**: `cd main && npm install && npm run build`
- **Output Directory**: `main/dist`
